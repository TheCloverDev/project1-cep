**slide 1:** AI Code Quality, security & developer trust
Artificial intelligence, also known as AI, has become a useful tool in software development, especially when it comes to generating code, debugging, and suggesting solutions.

But just because AI can write code, does that mean it can replace software engineers? 
To explore this question, we will focus on three important areas: The quality of AI-generated code, security and privacy risks, and how much professional developers actually trust these tools. 

**slide 2:** AI-generated code: Quality & reliability
One of the biggest concerns with AI-generated code is its overall quality.

According to Hall's 2024 book, *Coding with ChatGPT and Other LLMs*, generating code is only one part of the development process. Even if the code runs successfully, developers still need to make sure it's correct, readable, maintainable, and secure.

For example, AI might generate a function that produces the expected output but doesn't properly validate user input, which could create security vulnerabilities. This is why testing and code reviews remain important. 

**slide 3:** Security & Privacy Risks
Another major concern is security and privacy.

Researcher Al-Maamari (2026) conducted a study in which he compared five AI coding assistants using 14 different privacy criteria. 

The tools scored between 68 and 89.25 out of 100, showing that privacy protections can vary between providers. The research also identified concerns about confidential information, data collection practices, and how sensitive information is handled. 

It's important to mention that these scores were based on provider documentation, rather than tests of how secure the generated code actually was. This highlights why developers need to be careful about what information they share with AI tools. 

**Slide 4:** Developer Trust: Survey Results
Now, one of the most interesting questions is whether professional developers actually trust AI-generated code.

A 2025 study done by Madame and colleagues surveyed 51 professional developers about using AI coding assistants for privacy-related programming. The results showed that approximately 65% reported distrust and used alternative approaches for privacy-sensitive tasks. 
Additionally, almost 53% stated that they spent extra effort double-checking generated code for privacy, ensuring that AI assistants met the privacy requirements. 
About another 43% reported that they had never used AI assistants specifically to generate code to meet privacy requirements. And roughly 10% reported that it has poor output quality or buggy code & lastly, about 35% identified the extra effort as a challenge. 

Although this survey was of a small sample, it shows that many of these developers were cautious about relying on AI independently, especially when privacy was involved.

**Slide 5:** Can AI Replace Software Engineers?
So, based on these findings, can AI really replace software engineers?

AI can certainly assist with tasks like generating code, identifying errors, and suggesting improvements. These capabilities can make the development process more efficient.
However, software engineering involves much more than simply writing code.
Developers are also responsible for testing, protecting sensitive information, making design decisions, and ensuring software is reliable.
Our research doesn't prove that AI will never replace software engineers, but it does show that current AI coding tools still benefit from human judgment, particularly in security-sensitive situations.
Ultimately, AI is a powerful assistant, but human oversight and accountability remain essential
